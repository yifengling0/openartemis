## 实现

- authored clock 固定 60 帧/秒，`OA_EMOTE_FPS` 只控制姿态采样。Lua 的 `progress(frames)` 继续使用 authored frames。
- 转发并实现 `setVariable(name,value,frames,easing)` 的时长：支持从当前值插值、重定向、即时写入取消旧插值、step/skip 收束。
- 待机轨从单槽扩展为带权重的列表。`fadeOutTimeline` 保留旧轨到淡出完成，`fadeInTimeline` 允许新旧轨交叉；修复绝对轨淡出末端残留的半淡化姿态。
- `isTimelinePlaying` 返回 Lua boolean；原先返回数值 0，而 Lua 中 0 为真。
- 根据已解析的 eyeControl 增加自动眨眼，关闭/保持/睁开时间比例为 40/20/40。当前仅覆盖中性眼值，脚本显式控制优先；这项只有合成轨道测试，没有 TG3 模型视觉验证。
- GPU 主机在第一次脚本 tick 前启用 external pose，避免模型加载时先做一次 CPU 大画布光栅化。GPU 失败时重新光栅化当前变量，再上传 CPU 像素。
- 重用宿主 parts、部件顶点和 GLES 转换缓冲；图集按层和文件 uid 索引，用 source 数组替代每部件临时字符串键。
- GPU canvas 使用预乘合成，父透明度同时调制 RGB 与 alpha；画布尺寸变化时重建，非法部件/图集失败转入回退。
- 删除或解绑层时释放 canvas、图集与 CPU 上传纹理；清理只遍历人物缓存。同 id 重建使用文件 uid 区分旧 revision。
- 异步图片完成先被宿主 tick 消费，再决定是否跳过静态帧；同时失效包含未就绪图片的组缓存。
- CLI 工具的 FreeType 查找改用 CMake 标准模块，使 WSL 能构建 opfs/psb。

## 真实脚本测试

`tg3_emote_script_test` 执行游戏原始 e-mote.lua，并通过真实 GameRuntime/LuaBridge 验证：

- `ex.param` 的 250ms → 15 authored frames、`head_lr` → `head_LR`；`ex.reset` 的限时归零。
- 原样截取并执行的 `fg` 待机切换分支，验证两条循环在中点和末端的权重。
- `emote.action` 传入并行标志，`ex.stop` 使用 boolean 查询并停止指定轨道。
- `emote.vsync` 切换到游戏驱动的 progress 时钟、口型写入和 `lipstop` 归零。
- 原始 `parse.lua`、`func.lua` 的 explode、真实 `sound/vo/jsa/fem_jsa_30001.vol.csv` 与 `readlipcsv`/vsync 的完整读数链（第 9 个值 0.3）。

## WSL 结果

环境：Ubuntu 22.04、SDL2 2.33、WSLg/Mesa 23.2.1，实际 GL 上下文为 D3D12 Intel UHD 770。构建使用现有 `scripts/engine-linux.py` 的 native_env 与增量缓存。

本轮相关回归共 11 项：10 项通过，1 项因没有模型而跳过（`emote_timeline`）。通过项包括三个新测试及 Lua、合成器、层语义、render2、媒体、标签屏障和文本域回归。没有宣称全仓库测试通过：全目标构建还遇到原有 SDL2 测试 `audio_latency_bound_test.cpp` 使用 SDL3 的 `SDL_HINT_AUDIO_DRIVER`，本轮未改该无关文件。

同一份评审探针对旧/新二进制的复测：

| 检查 | 修改前 | 修改后 |
| --- | --- | --- |
| OA_EMOTE_FPS=30，推进 1000ms | 30 authored frames | 60 authored frames |
| alpha=0.5 白部件绘制到黑底 | RGB 64 | RGB 128 |
| 叠加父透明度 0.5 | — | RGB 64 |
| 两个 alpha=0.5 部件重叠 | — | RGB 191 |
| 同 id canvas 64×64 → 128×96 | 仍为 64×64 | 128×96 |
| 非法 source | 返回成功 | 返回失败 |
| 删除场景层后 canvas | 缓存残留 | 已释放 |
| 静态场景异步图片完成 | 无 repaint 通知 | 通知并重建组缓存 |

预热分配微基准为 64 部件、每部件 384 顶点、连续 10 姿态。为消除 WSL D3D12 驱动后台编译器的分配噪声，同一探针在 llvmpipe 上的旧/新结果为 **1280 → 0 次**（每姿态 **128 → 0 次**）。WSLg 硬件路径单独统计提交线程为 10 姿态 40 次，采样落在驱动调用中。该结果只覆盖已生成几何的提交，不包含完整模型求值、Lua 或游戏 FPS。

WSLg 游戏窗口执行了 360 帧启动冒烟，退出码 0，有 1920×1080 阶段画面、系统资源及 Lua 事件，backend_err 为 none。由于 PulseAudio 连接失败，成功运行使用 `SDL_AUDIODRIVER=dummy`，未验证音频输出；启动还提示缺少 `movie/lx2ymbutf.mp4`。这次运行没有人物模型，不作为 e-mote 人物画面或游戏性能验收。

```sh
cmake -S <source> -B <build> -DOA_ENABLE_TESTS=ON \

```

## 保留的边界

非零 easing 目前线性近似，并非完整原厂曲线。Hair/Bust 物理倍率、clampControl、模型 stencil/clip、复杂网格继承与外置/多文件模型仍需真实模型盘点和对照；本轮没有给这些能力增加假成功桩。组缓存目前仍使用整体失效，未实现按子树的选择性更新。显式变量与时间线的既有优先级也未整体重写。

后续应优先拿完整模型做多角色/换装和遮罩对照，再决定模型求值、索引网格或选择性组缓存优化。当前微基准不代表性能已经最优，也不能证明 HarmonyOS 真机收益。
